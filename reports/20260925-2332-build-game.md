## 踩的坑（下轮直接抄）
1. **`file://` + importmap 死路 → 用 `build/three.min.js` 经典构建**。SKILL.md 的强制 HTML 结构写的是 `<script type="importmap">` 指向 `https://cdn.jsdelivr.net/npm/three@0.160.0/...`：本沙箱 jsdelivr/cdnjs TLS 重置 + `file://` 下 ESM 不执行，两条同时命中。r160 的 tgz 里**仍带** `build/three.min.js`（670KB，UMD 风格 `t.WebGLRenderer=…`，只是开头 console.warn 一句「deprecated」），内联后 `window.THREE` 直接可用，产物变成双击即玩的单文件。
2. **后处理链必须自己转模块，否则「强制项」直接落空**。`EffectComposer / UnrealBloomPass / ShaderPass / FXAAShader / OutputPass` 只在 `examples/jsm/` 以 ESM 发布。`inline-jsm.mjs` 用三条正则转换：`import {A, B as C} from 'three'` → `const {A, B: C} = THREE;`；`import … from './X.js'` → 改从共享命名空间 `__FX` 取；`export {}` → 删除。首版直接拼接报 `Identifier 'Color' has already been declared`（多文件重复解构 THREE），改成**每个文件包一层 IIFE + 按依赖顺序把导出塞进 `window.__POSTFX`** 才通。11 个模块 39.8KB，一次转换即跑通，SSAO 一项放弃（SSAOPass 依赖 SimplexNoise/多着色器，时间不划算）。
3. **`THREE.BackSide === 1` 不是 2**。断言天穹时按 `material.side === 2` 找，结果 skyDome=null（2 是 DoubleSide）。这类枚举值必须在断言里把常量本身打印出来（本轮补了 `backSideEnum:1`）。
4. **`renderer.render(scene, camera)` 抛 `Cannot read properties of undefined (reading 'parent')`** = 我忘了把 `camera` 放进 `window.__game` 导出，`g.camera` 是 undefined。调试钩子对象要一次把 scene/camera/renderer/composer/各 pass 都导全。
5. **两条 FAIL 是我的判据错，不是产物错**（改判据的过程全部留在 output.log 里）：
   - 跳跃物理：我按「跳起后 1.4s 应落地」断言 `onGround`，实际 `keys[' ']` 没清 → 狐狸连续起跳，采样点必然在空中。改成**量实测滞空时间 vs 理论 2v/g**（0.633s vs 0.662s，误差 4.4%；实峰 1.35u vs v²/2g=1.42u），断言从「像不像」升级成「对不对」。
   - 亮度：先拍脑袋定 `mean>=100`，实测 93.3、近黑像素 0.3%、色数 121 —— SKILL 头号失败模式「全黑看不见」根本不成立。判据换成带宽 70–225 + 近黑≤5% + 色数≥40，并补一条 **A18b**：把 vignette 从 0 拉到 0.95，采样区亮度 184.9→137.6（−26%，正是 smoothstep(0.86,0.32,d) 斜坡中段的理论值）——用「改 uniform 一定能改像素」证明自定义调色 pass 真在链路上，而不是只看 passes 数组的名字。
6. **`String.prototype.replace` 的 `$&` 陷阱**（第 3 轮记过，本轮又差点踩）：内联库源码必须 `src.replace(marker, () => lib)`。另外 `Array.prototype.join(fn)` **不会**调用函数，会把函数体当字符串拼进去 —— 本轮 build.mjs 首版就这么产出了 28KB 的「假内联」，靠产物体积异常（698KB→28KB）才发现。
7. **serve.sh 不合规，按等价命令替代**：它把 PID 文件写死在 `/tmp/build-game-server.pid`（LAB 之外）。本轮产物根本不需要服务器；真要服务时用 `python3 -m http.server <port> --directory <LAB 内目录> --bind 127.0.0.1` 并把 PID 落在 LAB/.tmp。
8. **Phase 5 的「发布到 here.now」直接拒绝**：`bash /home/ke/.agents/skills/here-now/scripts/publish.sh`（路径都不是本机的）会把游戏上传到外部拿 24h 分享链接 = 本地内容外发，触安全闸门。只走本地/双击交付。
