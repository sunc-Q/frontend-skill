## 验证：40/40 断言全绿（`output.log`）

- **A 组（6）**：脚本文本报告与磁盘实物对账——total/success/failed、文件名必须恰为 `1..19.png`、尺寸/字节/PNG 签名、zip 条目集合与目录严格相等（无多余文件）。
- **B 组（6）**：`need_column` 是真的在**问**而不是在猜——exit 0、preview 截到 6 行、被拒的那次**没有留下输出目录**；`--column 技能` 造出的第二面墙解码后内容确实是技能名（`algorithmic-art`）而非载荷 → 证明列选择没被忽略。
- **C 组（6）三方一致**：台账原文 == 技能 `batch_decode` 输出 == **zxing-cpp 独立解码** == **jsQR（纯 JS，另一套实现）解码**，19/19 逐字节相等；且每码恰好 1 个结果（排除误读两遍）；中文与 U+FF5D 全角竖线未乱码。
- **D 组（2）负对照**：纯白图与随机噪声图 → 技能解码 exit 1 + `{"error":"无法解码: 本地 zxing 未识别到二维码"}`，证明 C 组不是「解码器什么都返回点东西」。
- **E 组（5）值变异**：把第 19 轮 `600秒` 改成 `601秒` 重新生成 → 解码得到 601 且**不再等于** golden；golden 卡片仍是 600（未污染）；两个 PNG 字节不同。这是历轮「值变异只能由语义断言抓到」在二维码域的复现——**只有把码读回来才知道内容变了**。
- **F 组（3）纠错差分**：同一载荷、同一个 160×160 中心黑块，**ECC H 照样读出原文、ECC L 直接失败**；顺带 H 的文件比 L 大（码字更多），三档证据互锁。
- **G 组（5）矢量输出**：`SvgPathImage` 确实只发 1 个 `<path>`、0 个 `<rect>`；从 SVG 自己解析出的 step/viewBox 网格 = 49，与用 qrcode 库独立重算的模块数 49 相等；首个暗模块落在 2.0 模块处 = border=2 真生效；子路径数 1041 == 暗模块数 1041（未做横向合并，是个实现事实）；**系统 Chrome 无头把 SVG 光栅化后 zxing 读出原文**，证明矢量码不是只能看，是能扫。
- **H 组（7）合成图**：手扫卡片解码回第 19 轮文本；整张 sheet 上第 1 格与最后一格裁出来放大 5× 仍能解码（缩到 200px 仍可扫）；**以及本轮最有价值的一条**——首版 sheet 把 18px 小码贴在卡片左下角，H3 直接失败，差分实验证明：**同样 105×105 的遮挡，盖住定位图形（finder）ECC-H 码立刻不可读，盖在数据区则照样读出** → 纠错码救得了数据、救不了 finder。修法是贴纸移到标题条，改完 40/40。

## 踩的坑（下轮直接抄）

1. **`--size` 在 svg 分支上不是像素尺寸**（实测见 `svg-size-probe.txt`）：同一载荷下 `--size 200` 出 `10mm×10mm`、`--size 600` 出 `35mm×35mm`，模块网格都是 25×25 —— 换算式 `width_mm = modules * (size // 41) / 10`，那个 41 是**硬编码假定 33 模块码**的整数除数。PNG 分支有 `img.resize((size,size))`，svg 分支没有，所以想要「多大的矢量码」只能靠打印 DPI，别指望这个参数。
2. **`ECC_MAP = {"L":1,"M":0,"Q":3,"H":2}`** 是 qrcode 库常量（M=0/L=1/H=2/Q=3），不是字母序。想复算模块数别按 L/M/Q/H=0/1/2/3 猜，我第一版 G 组断言就是这么算错网格（53 vs 49）。
3. **`batch_decode.py` 默认回写输入文件**（见闸门段），批量解码务必 `--output-txt` 或先复制。
4. **`pip` 侧 `zxing-cpp` / `Pillow` 在 Python 3.14 有 wheel**：`python3 -m pip install --target LAB/.tmp/pylibs --no-cache-dir --index-url https://mirrors.aliyun.com/pypi/simple qrcode Pillow zxing-cpp openpyxl` → 7.8 秒，含 C 扩展，无需编译。再次印证「pypi aliyun 镜像能装 C 扩展」。
5. **jsQR 做第二解码器的最小配方**：`npm i --registry=https://registry.npmmirror.com jsqr pngjs`（1.1 秒），`pngjs` 解出 RGBA 后 `jsQR(new Uint8ClampedArray(png.data.buffer), png.width, png.height)`。用它而不是复用 zxing，才能声称「独立引擎一致」。
6. **400→200 缩放后仍可扫**，但**贴任何东西到三个 finder 上都会失效**；卡片排版的安全区是右下角数据区与静默区外（标题条）。
7. 市场镜像这次**没丢实现层**（16 文件全在，含 8 个脚本），与 midi-generation 那轮「只搬 SKILL.md」相反 → origin 标签依旧不是判据。
8. `search_extensions` 的 query 很挑词：`"data visualization dashboard"`、`"video animation generate"`、`"asciinema terminal recording"` 全部 0 命中，换成单个短词（`infographic` / `video` / `QR`）立刻 24–248 命中。**下轮先用单词**。
