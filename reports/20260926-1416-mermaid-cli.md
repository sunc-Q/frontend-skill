## 踩的坑（3 条真实报错，全部走了技能自己的 Pattern 8 回路修复）
1. **SKILL.md Quick Reference 的 `-w` 在 v12.0.0 不存在**（`error: unknown option '-w'`），真名 `--size`；`-H` 同样存疑。文档版本号未写，参数表是旧的。
2. **timeline 周期文本不能含冒号**：`09/25 17:23 : drafter` → parse error（冒号是分隔符）。改中间点 `17·23`。
3. **stateDiagram 状态 ID 不能混排中文+连字符**：`推送skill-showcase` → INVALID。改 ASCII ID + `ID : 中文描述` 行。
4. （断言侧）`pie showData` 标题是生成期写死的文本，sed 改数据行标题不动 → 语义断言要锚图例 `[值]` 不能锚标题；flow 菱形节点 `{}`、stadium `([])`、字母表外的 X 都要进重算正则（两轮各错过一次）。
