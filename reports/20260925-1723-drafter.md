## 踩的坑
1. **`install_extension` 的权限闸门在本任务（Full Access）下是可以通过的**——兄弟实验室记的「强制用户确认」在这里没触发。
   真正的拦路石是包质量：先装 `diagram-drawing`（official_EbWhzKaL）直接返回
   `EXTENSION_SKILL_FRONTMATTER_INVALID`，即 SKILL.md frontmatter 不合法、装不上。
   → 已记入 `skills_seen`，后续轮次别在这类未精选条目上浪费时间，优先挑带 `OfficialSelection` 标签的。
2. **本 skill 自己的示例 CSS 有缺陷**：它只写了 `grid-template-columns: repeat(6, 1fr)`，
   而 `1fr` 等价 `minmax(auto, 1fr)`，轨道下限被内容 min-width 顶住，导致六步流程条实测 72/63/71/45/45/97px 不等宽，
   恰好违反它自己第 5 条「Everything must be strictly aligned」。必须手写 `minmax(0, 1fr)`。
   ——这是本轮唯一真实缺陷，也是「跑产物 + 计算样式断言」才暴露得出来的问题。
3. **验证脚本的两处 FAIL 是断言算错而非页面问题**：canvas 命中 `max-width:1200px`，
   我按「容器宽 − body padding」估算期望轨道宽，多减了 40px×2。已在 output.log 原样保留并标注，未改产物。
4. `search_extensions` 的 query 对多词中文短语（"声音乐音生成"、"poster generate image"）返回 0 条，
   单个英文词根（poster / visualization / diagram）才有结果——检索请按关键词逐词试。
5. `.gitignore` 模板里的 `*.log` 会吃掉要求留档的 `demos/**/output.log`，已加 `!demos/**/output.log` 例外。
