消融臂（同一份源码，只换 query）

  • ?probe=frozen —— 冻住 uTime，音频照跑 → 画面仍在变（变化只能来自音频）
  • ?probe=frozen,noaudio —— 时钟与音频一起拔掉 → 画面完全静止（changedPct 必须为 0）
  • ?probe=noaudio —— 音频读数清零、频谱与历史纹理不再更新 → 音频驱动的分量全部停住
  • ?probe=staticspectrum —— 喂一条与音乐无关的固定斜坡频谱 → 画面不随音乐变
  • ?probe=mislabel —— 64 带顺序反转后再上传 → 低频段跑到画幅另一侧，带映射真在生效
  • ?probe=samevariant —— 三个子视口都用 uVariant=0 → 分频三带失去差异
  • ?probe=noonset —— 起拍检测器不喂数据 → uBeat 恒 0，弹圈/闪烁带消失
  • ?probe=nomouse —— uMouse 只在初始化写一次 → 移动指针不再影响画面
  • ?probe=solid —— 着色器换成常量品红 → 证明绘制通路活着（黑屏检查表第 1 步）
  • ?probe=nogl —— 强制走无 WebGL 分支 → 显示降级提示而不是空白

互斥对：?probe=frozen（只拔时钟，画面必须仍变）与 ?probe=frozen,noaudio（时钟与音频一起拔，画面必须一像素都不动）。 三页实测：frozen 下像素变化 25.3% / 19.4% / 16.7%， frozen,noaudio 下变化 0 / 0 / 0 像素。

变异与还原

对产物做了 16 个故意破坏（value 6 / structural 8 / semantic 2）， 抓住 16 个；还原后 check-node 失败项与基线一致：是（明细见 evidence/mutation-strict.json）。 其中 S7 由设计就是「静态判据无反应、只有互斥消融臂能抓」，X1/X2 两条语义变异最初无人抓住，因此补了 D37 与 B16。
