个人主页 × sites:sites-building × 3 种风格

同一份事实内容（一位虚构独立开发者的作品、随记、近况与联系方式），三种互不相同的视觉主张。三页均为单个自包含 HTML，零依赖、零构建、零外链，直接双击打开。

Style A

和纸浮世绘 ukiyo

竖排名牌 + 引札式清单 + 版画水纹。纸色分三层代替阴影，一色朱红作关键线。

 Style B

深空星图 astro

近黑靛蓝 + 发丝金线 + 等宽数字。作品排成「星表」表格，随记是日志流，近况是三格遥测。

 Style C

像素掌机 pixel-console

四色绿阶屏 + 注塑灰外壳 + 4px 硬边。作品是五张卡带，投入时长用方格仪表读出。
三页共享同一组事实，仅设计主张不同；校验脚本 scripts/check.mjs 同时断言「事实一致」与「版式不同」。
