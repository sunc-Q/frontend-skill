Beacon 短链服务 · 运营后台

同一份 React 19 构建产物（IIFE bundle 逐字节相同），只替换 CSS 变量与主题层，得到三种彼此不混淆的风格。

1 · 商务白

浅色企业风：深藏青侧栏 + 白面板 + 蓝强调，6px 圆角、大写小标签，--fs-kpi:26px。

 2 · 单色暗

零彩色终端感：全站等宽字体、直角（radius 0）、大写字距 0.16em，状态只靠字重与符号表达。

 3 · 95 桌面

复古系统风：灰底斜角边框（凸起/凹陷两套）、蓝渐变标题条、Tahoma、取消大写、气泡提示为淡黄。
页面均可直接双击打开（file:// 下可交互），或在本目录执行 python3 -m http.server 预览。
四个分区（总览 / 短链管理 / API 密钥 / 服务设置）共用同一组件树，含搜索、筛选、排序、行展开、两步删除、密钥显隐与复制、表单校验。
