前端 Skill 验证流水线 · 系统说明图

HOURLY FRONTEND-SKILL VERIFICATION PIPELINE — STRUCTURE & DECISION FLOW

A · 主控链路 SINGLE SESSION, NO INHERITED CONTEXT

01 / READ
读记忆
  • records/work-log.md
  • state/state.json
  • tried · used_styles
唯一跨运行入口
02 / PICK
选题去重
  • skill × scenario
  • 3 种未用过风格
  • 跳过不可用来源
见 B 决策树
03 / BUILD
按技能构建
  • artifacts/<run>/
  • 1 skill · 1 scenario
  • 不扩大范围
失败也继续收尾
04 / CHECK
校验
  • node vm 语法桩
  • 断言脚本
  • computed style 复核
缺陷在此暴露
05 / CLEAN
收尾
  • 删 node_modules/dist
  • 删 .tmp 与 /tmp
  • 单场景 < 50MB
脚本先抄进报告
06 / WRITE
记录与推送
  • reports/<run>.md
  • state.json 回写
  • git push (SSH)
闭环
◀ 回边：05 清理失败 → 03 重建（中间产物不入库，.gitignore 已排除） 06 推送不可达 → 记录留痕后退出，不留脏工作区

B · 去重判定 DEDUCTION: SKILL × SCENARIO × STYLE

B1 · 组合是否试过

查 state.tried[] 的 skill + scenario 命中 → 弃用，取下一候选 未命中 → 进入 B2

B2 · 风格是否用过

查 state.used_styles[]（当前 21 项） 要求 3 种彼此差异明显的新风格 冲突 → 换风格组合，不换场景

B3 · 来源是否可用

查 state.skills_seen[] 与 environment_notes[] 网络不可达 / 需用户确认安装 / 产物不落盘 → 不再探测 仅 ~/.qoder-cn/skills/ 已装技能可直接调用

B4 · 无候选时

work-log.md 追加「本次无新组合可试」+ 卡点 禁止重复已试组合 本轮直接结束

D · 环境约束 WHAT THE PIPELINE CANNOT ASSUME

网络

github.com HTTPS 被 TLS 重置 → 只走 SSH；npm 走 registry.npmmirror.com；skills.sh / raw.githubusercontent 不可达

权限

extension-market 安装强制用户确认 → 无人值守轮不得安装外部技能

预览

框架构建产物为 ES Module，file:// 不执行 → 需内联成单文件版；本图原生 HTML 双击即开

磁盘

单场景产物 < 50MB；实验室总量按轮累加，收尾清单写入 runs[].cleanup
