松塔 Songta · 定价页三风格对照

同一份 React 产物（三页内联的 <script> 是同一份 252,795 字节 bundle，逐字节相同，由 style-check 断言而非手抄）， 只换样式层得到三种成立风格。每页双击即可离线打开，零外链。

包豪斯构件 bauhaus

三原色对应三档套餐，圆/方/三角是唯一的图形语言；2-3px 实描边、零圆角、硬投影，标题全大写。

preview/pricing-bauhaus.html

千禧镀铬 y2k-chrome

深色底 + 虹彩渐变描边，价格数字用铬合金渐变裁切文字；玻璃拟态、大圆角、光晕阴影，2000 年系统设置窗泡进肥皂泡。

preview/pricing-chrome.html

工程蓝图 blueprint

深蓝图纸 + 双层网格，全站等宽字体与 0.06em 字距，面板左上角一道图框分度线，选中态用引出线表达。

preview/pricing-blueprint.html
  • 算价台：月付/年付、CNY/USD、席位滑杆（1-100，苗木档钳到 3 席）、三档实时价格与人均、阶梯提示
  • 增值模块：按席位与按组织两类计价，换档时自动剪枝，冠层档显示「已含」与「需要冠层」两种锁定态
  • 对比表：16 行 × 3 档，分组筛选 + 只看差异 + 能力搜索，行数与空态可断言
  • 报价单：按需动态加载的模块，明细行相加恒等于合计；邮箱校验通过后写入带版本号的 localStorage
  • 常见问题：热度排序（toSorted）+ 搜索 + 手风琴 + 无命中空态

本页只是入口对照。index.html 是本项目「代码分割版」构建入口（vite build --config vite.split.config.ts）， 用来量出报价单模块与分析模块确实落在首包之外；preview/ 下的三页才是双击可开的成品。 复现步骤与踩坑记录见 ../../reports/20260925-19-sites-react-pricing.md。
